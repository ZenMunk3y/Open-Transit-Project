# Ford Transit 350 L3H3 AWD MK8 Vehicle Specification

## Overview

This document records the technical specification and reference information for the Open Transit Project (OTP) vehicle development target:

**Ford Transit 350 L3H3 AWD MK8 - Right-Hand Drive (RHD)**

The purpose of this document is to provide an engineering reference for:

- Accurate blueprint creation
- CAD reference development
- Digital twin construction
- 3D modelling
- Blender asset creation
- Interior and cargo area design

The final objective is an editable, accurate digital representation of the vehicle.

# Accuracy Classification

All measurements should include a confidence rating.

|---|---|

| Medium | Multiple reliable references |
