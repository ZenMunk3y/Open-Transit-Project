# Ford Transit 350 L3H3 AWD MK8 Reference Sources

## Overview

This document records the reference material used during the development of the:

**Open Transit Project (OTP)**

**Ford Transit 350 L3H3 AWD MK8 - Right-Hand Drive (RHD) Digital Twin**

The purpose of this document is to maintain traceability between:

- Technical specifications
- Blueprint drawings
- CAD references
- 3D models
- Measurements
- Visual references

Every major modelling decision should be linked back to a reference source where possible.

---

# Source Priority

Reference sources should be evaluated using the following priority system:

| Priority | Source Type | Reliability |
|---|---|---|
| 1 | Manufacturer technical documentation | Highest |
| 2 | Ford Body Builder drawings | Highest |
| 3 | Official Ford specifications | High |
| 4 | Workshop manuals | High |
| 5 | Verified physical measurements | Medium |
| 6 | Photographic references | Medium |
| 7 | Estimated measurements | Low |
