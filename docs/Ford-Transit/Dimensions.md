# Ford Transit 350 L3H3 AWD MK8 Dimensions

## Overview

This document records the dimensional reference information for the:

**Ford Transit 350 L3H3 AWD MK8 - Right-Hand Drive (RHD)**

This document forms part of the Open Transit Project (OTP) digital twin development process.

The purpose of this document is to provide the dimensional foundation for:

- Blueprint generation
- CAD reference drawings
- Digital twin development
- Blender modelling
- Cargo area design
- Conversion planning

All confirmed measurements will be recorded in metric units.

# Digital Twin Reference System

## Coordinate System

All modelling will use real-world scale.

Recommended Blender setup:

- Units: Metric
- Scale: 1 Blender Unit = 1 Metre

---

## Primary Datum

Recommended vehicle datum:

- Vehicle centreline = Y0
- Ground plane = Z0
- Vehicle length axis = X
