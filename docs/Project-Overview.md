# Project Overview

## Purpose

The Open Transit Project aims to create a collection of open resources for studying and recreating transit vehicles digitally.

## Main Areas

### Research

Collecting:

- Technical specifications
- Dimensions
- Historical information
- Reference imagery


### Modelling

Creating:

- Accurate 3D models
- Components
- Interiors
- Accessories


### Documentation

Recording:

- Design decisions
- Measurements
- Modelling processes
