# Open Transit Project

## Overview

The Open Transit Project is an open development initiative focused on creating accurate, reusable, and accessible resources for transit vehicle design, documentation, and digital modelling.

The project combines:

- Vehicle research
- Blueprint creation
- 3D modelling
- Digital asset development
- Documentation
- Open collaboration

## Current Project Focus

### Ford Transit Blueprint Project

The first major development goal is the creation of a detailed Ford Transit reference package including:

- Vehicle dimensions
- Blueprint drawings
- Reference imagery
- 3D modelling guides
- Blender assets
- Export-ready models

## Project Philosophy

The goal is to create accurate digital representations while maintaining an organised and transparent development process.
