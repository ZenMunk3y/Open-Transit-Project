# Contributing Guidelines

Thank you for your interest in contributing to the Open Transit Project.

## Development Principles

Please aim for:

- Accuracy
- Clear documentation
- Consistent file organisation
- Respectful collaboration

## Adding Research

Research documents should include:

- Source information
- Measurements
- Assumptions
- Notes about accuracy

## Blender Assets

Please:

- Apply sensible naming conventions
- Keep models organised
- Include scale information
- Document major changes
